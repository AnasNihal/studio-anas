# Studio Anas

A motion-led creative portfolio built with React and Vite, featuring project browsing, service information, and contact sections.

The interface uses GSAP with ScrollTrigger for animations and React Lenis for smooth scrolling.

## Run locally

Requires Node.js and npm.

```bash
npm install
npm run dev
```

Use `npm run build` to create the production build and `npm run preview` to preview it locally.
